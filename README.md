## 🌐 OVERVIEW / PRÉSENTATION
**LUCY_OS** est une interface de gestion de catalogue de films ultra-rapide inspirée des terminaux de science-fiction. Elle utilise un système de recommandation unique basé sur l'affinité des tags pour transformer votre bibliothèque en une expérience d'exploration personnalisée.

**LUCY_OS** is a high-speed movie catalog interface inspired by sci-fi terminals. It uses a unique tag-affinity recommendation system to turn your library into a personalized exploration experience.

## 🔑 CONFIGURATION: TMDB API
**FR :** Pour que le système récupère les synopsis, les notes et les logos des plateformes de streaming (Netflix, Prime, etc.), vous devez insérer votre propre clé API.
1. Créez un compte sur [The Movie Database (TMDB)](https://www.themoviedb.org/).
2. Allez dans vos paramètres pour obtenir une **API Key (v3 auth)**.
3. Insérez-la dans le champ de l'interface web.

**EN :** To fetch synopsys, ratings, and streaming provider logos, you must provide your own API key.
1. Create an account on [The Movie Database (TMDB)](https://www.themoviedb.org/).
2. Go to settings to get your **API Key (v3 auth)**.
3. Insert it into the web interface field.

## 🧠 SYNERGY RECOMMENDATION & FILTERS
**FR :** Le cœur du système est le "Neural Matching". 
- **Favoris (❤️) :** Le système extrait les tags (ex: *Cyberpunk, Robots, Espace*) des films que vous aimez.
- **Filtres Avancés :** À vous de diriger la machine. Si Lucy propose des robots, vous pouvez filtrer par *Western*, *Documentaire* ou *Animation* pour affiner le résultat.
- **Menus :** - `REGION` : Changez la détection des plateformes de streaming (FR, US, JP, etc.).
    - `PROFILES` : Gérez vos sessions.
    - `GENRES` : Filtrez instantanément par catégories (Action, Sci-Fi, etc.).

**EN :** The heart of the system is "Neural Matching".
- **Favorites (❤️):** The system extracts tags (e.g., *Cyberpunk, Robots, Space*) from your liked movies.
- **Advanced Filters:** You stay in control. If Lucy suggests robots, use the *Western*, *Documentary*, or *Animation* filters to refine the results.
- **Menus:** - `REGION`: Toggle streaming provider detection (FR, US, JP, etc.).
    - `PROFILES`: Manage sessions.
    - `GENRES`: Instant filtering by categories (Action, Sci-Fi, etc.).
